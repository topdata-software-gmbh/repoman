# AGENTS.md

## Read first

- [_ai/goals.md](_ai/goals.md) — what RepoMan is primarily for, its non-goals, and its
  simplicity and macOS requirements. Treat it as the source of truth when
  deciding scope or trade-offs. If a requested change conflicts with it, say so
  and confirm before implementing.

## Project context

- `_ai/conventions.md` holds the exported engineering conventions. It is
  generated by `ruleman`; do not edit it by hand.
- Architecture decisions live in `_ai/technical_decisions/`.
- Feature specs live in `specs/`.
- The Rust core in `src-tauri/` is shared by the Tauri desktop app and the axum
  web server; the Vue UI in `src/` serves both.

## Commands

```bash
pnpm install        # install frontend dependencies
pnpm tauri dev      # desktop app + Vite dev server
./scripts/dev-up.sh # browser mode (Rust web API + Vite)
pnpm typecheck      # vue-tsc
pnpm test           # vitest
pnpm build          # type-check and build dist/
```
